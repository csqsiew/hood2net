# Returns the neighborhood size (i.e., degree) for all or a subset of nodes in the language network.

Returns the neighborhood size (i.e., degree) for all or a subset of
nodes in the language network.

## Usage

``` r
get_neighbor_size(network, node_name = NULL)
```

## Arguments

- network:

  An `igraph` network object, generated by
  [`make_network()`](https://csqsiew.github.io/hood2net/reference/make_network.md)
  or
  [`make_network_sep()`](https://csqsiew.github.io/hood2net/reference/make_network_sep.md)
  functions.

- node_name:

  A vector containing node names to obtain values for. Node names must
  be found in `igraph::V(network)$name`. If unspecified, the default is
  to return values for all nodes in the network.

## Value

A named numeric vector.

## Examples

``` r
# Use the demo data for executing examples

  test <- make_network(sample1)
#>   |                                                                              |                                                                      |   0%  |                                                                              |========                                                              |  11%  |                                                                              |================                                                      |  22%  |                                                                              |=======================                                               |  33%  |                                                                              |===============================                                       |  44%  |                                                                              |=======================================                               |  56%  |                                                                              |===============================================                       |  67%  |                                                                              |======================================================                |  78%  |                                                                              |==============================================================        |  89%  |                                                                              |======================================================================| 100%
  get_neighbor_size(network = test) # all nodes
#>     1_cat     2_bat     3_cut     4_cap     5_hat    6_chat    7_heat    8_hate 
#>         5         2         1         1         5         2         1         1 
#> 9_spinach 
#>         0 
  get_neighbor_size(network = test, node_name = "1_cat") # for 1 node
#> 1_cat 
#>     5 
```
