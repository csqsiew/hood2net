# To check if edit_size is a whole number or not. Internal function used by `make_network()` and `make_network_sep()`.

To check if edit_size is a whole number or not. Internal function used
by
[`make_network()`](https://csqsiew.github.io/hood2net/reference/make_network.md)
and
[`make_network_sep()`](https://csqsiew.github.io/hood2net/reference/make_network_sep.md).

## Usage

``` r
is.wholenumber(x, tol = .Machine$double.eps^0.5)
```

## Value

TRUE or FALSE.
